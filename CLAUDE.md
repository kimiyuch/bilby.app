## Agent skills

### Issue tracker

Issues live in GitHub Issues on kimiyuch/bilby.app, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root, created when they're first needed. See `docs/agents/domain.md`.
